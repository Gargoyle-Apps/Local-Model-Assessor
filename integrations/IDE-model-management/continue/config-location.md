# Config location

**Default Continue config:** `~/.continue/config.yaml`

Generated LMA config (tracked path): `integrations/IDE-model-management/continue/generated/config.yaml`  
`sweep-ide-config.py` merges LMA-managed entries into `~/.continue/config.yaml` (backs up first).

To keep an untracked reference copy of your live config in this repo folder:  
`cp ~/.continue/config.yaml integrations/IDE-model-management/continue/config.yaml`  
See [IDE.md](../IDE.md) for details.
